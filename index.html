CTF Learning Assistant

Solo project
Question
Most CTF tools just hand you an answer — what if one taught the underlying concept first?
Approach
Built browser-based detectors for 10+ encodings (Base64, Hex, Binary, ROT13, Vigenère, Morse, Octal, A1Z26, URL, XOR/Base32).
Discovery
Chi-squared frequency analysis can guess a Caesar shift without brute-forcing all 26 — letters gossip about themselves.
Improve
Extend the frequency analysis so it holds up on short ciphertexts, where the statistics get shaky.

MediFind

3-person team · supervised by Dr. Kaushiki Roy
Question
Can a chatbot triage symptoms and point someone to the right specialist, not just "a doctor"?
Approach
Owned the full frontend, a semantic specialist-matching layer using Sentence Transformers, and symptom extraction/classification via Groq/LLaMA + FastAPI, backed by a keyword fallback.
Discovery
"AI-powered" search still needs a boring backup plan for when the vectors don't cooperate.
Improve
Tighten the fallback logic so it reads less like a backup and more like a second opinion.

Fruit Recognition — VGG16 Transfer Learning

3-person team
Question
Can a model tell 15 kinds of fruit apart — and does the choice of loss function actually matter?
Approach
Transfer-learned VGG16 backbone (frozen conv layers, custom classifier head), comparing CrossEntropy vs Focal Loss, plus the training loop.
Discovery
Best experiment hit 97% test accuracy — turns out fruit is more classifiable than people.
Improve
Test against messier real-world photos instead of clean dataset images.
PythonPyTorchTransfer Learning
